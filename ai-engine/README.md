# GAME ON AI ENGINE — bootstrap branch

This isolated workspace is being developed on `ai-engine/bootstrap`. The existing `main` branch has not been modified.

The complete v0.1 source package is attached in the project conversation as `GAME_ON_AI_ENGINE_Foundation_v0.1.zip`. Extract the `ai-engine/` folder from that package into this workspace and follow its README.

The starter includes a Next.js dashboard, FastAPI API, SQLite project storage, prompt-only or GDD-based planning, a configurable OpenAI-compatible planner, and API tests.

This is a development foundation, not a finished game generator. Unreal/Unity project generation, durable workflows, asset generation, automated QA, cloud build workers, and platform-specific exports remain future milestones. Console builds require authorized developer access; iOS builds require Apple signing and macOS/Xcode.
